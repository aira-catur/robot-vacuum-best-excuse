A Python program (`main.py`, standard library only, deterministic, no network) that writes one line — the funniest excuse a robot vacuum can give for missing a spot — to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).

The line:

> My sensors detected a Lego in that corner. I am a vacuum, not a bomb disposal unit.
